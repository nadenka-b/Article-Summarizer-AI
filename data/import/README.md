# Источники данных и лицензии

## Корпус научных статей

| Что | Где | Лицензия |
| --- | --- | --- |
| PDF-файлы статей (100 шт., пополняется до 1000+) | `data/raw/pdfs/` | индивидуальные, см. `licenses.md` |
| Реестр статей: название, авторы, год, журнал, DOI, источник, лицензия | `data/import/licenses.md` | — |
| Обработанные JSON (текст, язык, аннотация) | `data/processed/NNNN.json` | наследуют лицензии исходных статей |
| Тематическая классификация корпуса (ручная разметка) | `data/import/article_categories.json` | создано авторами проекта |

Подавляющее большинство статей корпуса распространяется по лицензии
**CC BY 4.0** (разрешено повторное использование с указанием авторства).
Точные лицензии по каждой статье — в таблице `licenses.md`.

## Глоссарий

| Что | Где | Лицензия |
| --- | --- | --- |
| Встроенный набор (510+ русских терминов, аббревиатур, шаблонных фраз) | `backend/data/glossary.py` | создано авторами проекта |
| Термины, добытые из корпуса | таблица `glossary` в БД | наследуют лицензии корпуса |

## Пайплайн обновления данных

1. Новые PDF кладутся в `data/raw/pdfs/` с именем `NNNN_статья.pdf`;
   строка с метаданными и лицензией добавляется в `data/import/licenses.md`;
   при необходимости уточняется `article_categories.json`.
2. `python scripts/import/prepare_articles.py` — извлекает текст и аннотации
   **только для новых** статей (уже обработанные пропускаются; `--force` —
   переобработать всё).
3. `python scripts/import/import_articles.py` — импорт в БД (идемпотентно:
   существующие статьи пропускаются, `--update` — обновить) + заполнение
   базы знаний парами «текст → аннотация».
4. `python scripts/import/add_glossary.py [--mine-corpus]` — глоссарий
   (идемпотентно; `--mine-corpus` добывает частотные термины из корпуса).
5. `python scripts/retrieval/reindex_kb.py` — перестройка индексов RAG
   (BM25 + Qdrant).
